# Time-management-helper-with-internet-connection

## Описание проекта

Этот проект является улучшением 1 проекта, изменения заключаются в сохранении списка задач на сервере, получении списка задач с помощью интернет-соединения с сервером. Благодаря этому пользователь может пользоваться приложением с разных устройств, не теряя задач, внесенных с других устройств.

## Изменения функционала

- Получение списка задач от сервера в json формате

- При добавлении/изменении задач отправляются команды на сервер

- Добавление аккаунта для пользователя (при входе в приложение будет необходимо зарегистрироваться/авторизоваться)

## Архитектура

Для сохранения данных используется SQLAlchemy и sqlite. В базе данных "users" будут храниться экземпляры класса User, который отвечает за конкретного пользователя и имеет поля login, password, problems - логин, пароль и список задач в json формате.
Для передачи данных между сервером и клиентом используется . Сервер будет сохранять изменения в базе данных, при регистрации нового пользователя будет добавляться строка для этого пользователя.

## Запуск проекта

Для работы проекта необходимо, чтобы был запущен сервер. Для запуска сервера локально необходимо выполнить команду:

```bash
python3 src/server.py host port
```

где ```host``` - ip-адрес сети,  ```port``` - порт для соединения.

Для запуска самого проекта выполните команду:

```bash
python3 main.py host port
```

где ```host``` и ```port``` - аргументы, аналогичные аргументам сервера (ip-адрес и порт для сервера и клиента должны совпадать)

Для передачи данных между сервером и клиентом, возможности сервера асинхронно работать с несколькими пользователями используется модуль asyncio. Сервер будет сохранять изменения в базе данных, при регистрации нового пользователя будет добавляться строка для этого пользователя.
